# 错题本（CuotiBen）

一个**本地运行**的错题本程序：把作业错题拍照发给 AI，自动识别、讲解、归档，再按遗忘曲线安排复习。
Windows 单机使用，**双击即用，无需安装 Python 或任何依赖**，数据全部存在自己电脑里。

> 服务端纯 Python 标准库实现（唯一随包的第三方库是纯 Python 的二维码库 segno），
> 前端是单文件 HTML，无构建步骤、无框架、无 CDN 依赖。

## 功能

- 📷 **拍题录入**：拍照/截图 → AI 识别题目并检查讲解 → 一键归档（支持一张图多题的整卷识别）
- 🔁 **遗忘曲线复习**：自动排期、判题快捷键、复习日历、今日到期优先补练
- 📊 **宽屏看板**：桌面端打开一个 1440×900 的独立看板窗口（问候横幅、数字卡、各科进度、优先补练、内嵌日历、手机扫码二维码）
- 📱 **手机同看**：手机与电脑同一 WiFi，扫码即用竖版界面，数据是同一份
- 🏷️ **错因标签 / 知识点**：按标签专练某一类错题，统计页按知识点/错因汇总
- 💾 **数据导入导出**：一键导出整包 zip（错题 + 复习记录 + 图片 + 听力音频，文件名自动带日期），
  换电脑「合并导入」（谁改得新听谁）或「覆盖导入」（整库还原，导入前自动备份）
- 🖨️ **打印**：按家长版/孩子版排版打印错题
- 🌙 **多主题**：浅色 / 深色 / 「纸墨」暖色皮肤

## 快速开始（推荐：下载打包好的 exe）

1. 到 [Releases](https://github.com/sunyg007/cuotiben/releases) 下载最新版的 `CuotiBen-standalone-<日期>.zip`（页面上的中文标签即「错题本-单机版」）；
2. 解压到任意文件夹（整个文件夹一起放，数据跟着文件夹走）；
3. 双击 `错题本.exe` —— 自动弹出宽屏看板窗口，服务同时启动；
   关闭看板窗口（或任务栏「看板服务」小窗）= 服务一起退出；
4. 手机扫码（看板右上角二维码）即可在手机上用竖版界面访问同一份数据。

不配置 AI Key 也能手动录入错题、复习、看板统计等全部功能；只有「拍题 AI 识别」需要到
「设置」页填一个自己申请的 API Key（默认对接硅基流动，也可改 DeepSeek 等任意
OpenAI 兼容接口）。Key 只保存在本机 `config.json`，不会上传。

## 从源码运行 / 打包

```bat
:: 运行（需本机装有 Python 3.8+，无第三方依赖）
python server.py
:: 打开 http://127.0.0.1:8765

:: 打包 exe（需 pip install pyinstaller）
制作exe.bat
:: 产物在 dist\错题本\，整个文件夹即可分发
```

也可以用桌面形态：`错题本看板.pyw`（双击 = 看板窗口 + 后台服务一体）、`面板.pyw`（带二维码的小控制窗）。

## 数据导入 / 导出

在「设置 → 💾 数据」：

| 操作 | 用途 |
| --- | --- |
| ⬇️ 导出数据（.zip） | 整包备份，文件名自动带日期（如 `错题数据导出-20261027.zip`） |
| 📥 合并导入 | 两台电脑都录过题，按「谁改得新听谁的」拼成一本，复习记录去重 |
| ⚠️ 覆盖导入 | 用所选 zip 整库替换当前错题本（导入前自动备份到 `backup_导入前_日期\`） |

## 目录结构

```
错题本.exe            主程序（看板窗口 + 后台服务一体）
_internal\            运行时资源（PyInstaller 打包产物）
config.json           配置与 API Key（不含 Key 也能用）
data\                 全部数据：app.db + images\ + audio\
使用说明.md           面向使用者的说明
```

源码仓库：

```
server.py             服务端（纯标准库：HTTP 服务 + SQLite + AI 调用）
web\index.html        前端单文件（看板/列表/详情/复习/设置）
segno\                 二维码库（纯 Python，随包分发）
错题本看板.pyw         宽屏看板入口（Edge/Chrome 应用模式窗口 + 服务同开同关）
面板.pyw              传统小控制窗入口
selftest.py           接口自测（python server.py 起服务后运行）
制作exe.bat           PyInstaller 一键打包
```

## 隐私与安全

- 所有错题数据、图片只存在本机 `data\` 文件夹，程序不上传任何数据（AI 识别是你本机
  直连你填的 AI 服务商）；
- 局域网访问仅监听本机端口，跨设备访问走你自己的局域网。
